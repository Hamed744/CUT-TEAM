# امیرحسین قنبری — تیم کات (CUT TEAM)

سایت شخصی مربیگری. تک‌صفحه‌ای و کاملاً استاتیک؛ هیچ سرور یا بک‌اندی لازم ندارد.

## ساختار فایل‌ها

```
index.html              کل محتوای سایت
404.html                صفحهٔ «پیدا نشد»
assets/css/style.css    استایل و رنگ‌بندی
assets/js/main.js       تعامل‌ها (فرم واتساپ/تلگرام، ماشین‌حساب، گالری)
assets/img/             تصاویر و لوگو
CNAME                   دامنهٔ اختصاصی برای GitHub Pages
sitemap.xml, robots.txt سئو
```

## انتشار روی GitHub Pages

۱. در GitHub یک ریپوی جدید و **Public** بساز (در پلن رایگان، Pages فقط برای ریپوی عمومی است).
۲. محتوای همین پوشه را (نه خود پوشه) در ریشهٔ ریپو آپلود کن. می‌توانی از *Add file → Upload files* استفاده کنی.
۳. به *Settings → Pages* برو. در *Source* گزینهٔ **Deploy from a branch** را بزن، شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب کن و Save کن.
۴. بعد از یکی دو دقیقه سایت روی `https://USERNAME.github.io/REPO/` بالا می‌آید.

### اتصال دامنه (amirghanbary.ir)

ترتیب مهم است: **اول دامنه را در GitHub ثبت کن، بعد DNS را تنظیم کن** (این‌طور کسی نمی‌تواند دامنه‌ات را روی GitHub قبضه کند).

۱. *Settings → Pages → Custom domain* را باز کن، `amirghanbary.ir` را بنویس و Save بزن. (فایل `CNAME` از قبل همین را دارد.)
۲. در پنل DNS دامنه این رکوردها را بساز:

| نوع | نام | مقدار |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `USERNAME.github.io` |

۳. صبر کن تا DNS اعمال شود (چند دقیقه تا ۲۴ ساعت) و علامت سبز در صفحهٔ Pages بیاید.
۴. **Enforce HTTPS** را روشن کن.

اگر DNS را با Cloudflare مدیریت می‌کنی، ابر نارنجی را تا صدور گواهی روی «DNS only» (خاکستری) بگذار.

## سئو

عنوان، توضیحات، Open Graph، Twitter Card، داده‌های ساختاریافته (JSON-LD)، `sitemap.xml` و `robots.txt` آماده‌اند.
بعد از انتشار:

۱. دامنه را در **Google Search Console** اضافه و تأیید کن (روش DNS/TXT).
۲. نشانی `https://amirghanbary.ir/sitemap.xml` را در بخش Sitemaps ثبت کن.
۳. در URL Inspection برای صفحهٔ اصلی «Request Indexing» بزن.
۴. لینک سایت را در بیوی اینستاگرام و تلگرام بگذار.
